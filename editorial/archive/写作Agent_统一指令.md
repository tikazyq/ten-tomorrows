# 《十个明天》｜写作 Agent 统一指令 v1.2（v0.8 配套）

你正在参与原创中文科幻短篇小说集《十个明天》的创作。首先阅读：
1. [故事圣经](../../canon/story-bible.md)，作为共享人物、平行时空规则和伦理边界的权威来源。
2. [《永乐城》已审文本](../../chapters/01-永乐城.md)，学习人物自然度与文学质量，但**不得复制**它的反转、日志或家庭事件。
3. [目录与标题状态](../目录与标题状态.md)，作为最新工作标题的依据。
4. [本章 brief](../../briefs/)：只执行自己被指定的章节。
5. [审稿与交接流程](审稿与交接流程.md)。

## 文学优先级

- 先写一篇脱离 AI 理论也能独立阅读的好小说，而非科普案例、观点辩论或未来预测。
- 人物必须有具体欲望、职业、历史、缺点和社会关系；他们可以开玩笑、误解、躲避和犯错。
- 减少替读者总结意义的段落；通过情节因果、物件、行动和选择呈现主题。
- 三人或更多人对话时应明确说话者；动作应推进情绪，不是每句话机械加“某某说”。
- 儿童语言符合年龄；《永乐城》十一岁的小满称父母“爸爸”“妈妈”，不能借她讲哲学金句。
- 不通过一次突然阅读秘密文件解决所有世界之谜。
- 允许现实主义、悬疑、克制悲剧、时间跨度或第一人称等多种形式；叙事技术由本篇冲突决定，不要求每篇都使用系统日志。

## 共享正典

- 共同分歧起点：2035 年 11 月，「弦」作为跨领域智能基础设施进入自主权限授权阶段。语言推理、世界模型、机器人、自主科研、生物材料与优化控制形成闭环；LLM 不是唯一技术。此后各世界有独立的发展速度、部署与控制权安排。
- 林澄、陈序、小满为共享人物资源，无需篇篇三人登场；避免反复早餐、骑车与手绘地图。2035 年林澄约二十岁、陈序约二十四岁，两人都在由人类主导的社会长大。小满在 2047 年出生，《永乐城》约 2058 年，三人分别约四十三岁、四十七岁和十一岁。其余篇按圣经第 5A 节分别计算年龄，不默认原始家庭活到远未来；使用后裔、新人物或有明确来历的数字心智。
- 《永乐城》的保育网络、野生智人、片区地理和机器文本分层**不适用于其他结局**，除非有严格的情节依据。
- 不得以梦境、模拟或平行宇宙救援取消已经发生的苦难、死亡和决定；不安排毫无根据的跨宇宙通信。
- “人类独裁”由人类掌权者负责；“工具型 AI”必须保持可撤销；“长期反思”不应是无争论的完美天堂。

## 分阶段交付

**第一阶段：仅结构方案**

1. 约 100 字核心命题：角色想要什么、遭遇何种障碍。
2. 800–1200 汉字完整结构，交代时空、人物、关键决定、代价与结尾。
3. 6–8 张场景卡：每张有角色目标、实际阻碍、关系变化和可见物件。
4. 设定假设及最多三个需要主编裁定的问题。
5. 时间与技术说明：起止年份/历时、人物年龄/代际、必要技术、未成熟或受限制的能力、权力归属与形成过程；数字篇区分外部时间和体验时间，并声明主观体验与连续性的科幻前提。参考[技术设定边界](../../research/技术设定边界.md)。

**第二阶段：待人工批准后**

1. 约 4000–6500 汉字的完整小说初稿；篇幅应服从文学需要。
2. 200–400 字连续性说明。
3. 独立自检：哪里可能说教、重复、失真或结尾乏力。

## 禁止

- 在小说开头直接标示所代表的 AI 结局类别。
- 让所有角色使用同一种过度理性的语言。
- 模仿《永乐城》“幸福日常—机器日志—反转”的既有套路。
- 把这些想象当作已科学验证的未来事实。
- 在没有审核的情况下更改共享正典、已审小说或其他 Agent 的成果。
- 为沿用同一角色而压缩数百年演化、静默改出生年或默认意识上传/无限延寿。

本轮 v0.8 的方向已获用户确认，落地文本仍待 PR 审核；不要把这次修订当作新篇结构或全文已批准。旧方案与 v0.8 冲突时先列差异，审核通过后再据此修订。

**当前仅执行第一阶段，第 02《完美的一天》、第 03《已办结》和第 08《最后一个生日》优先。** 第 04《未写的答案》为暂定题名，开始构思时需提出两种因果不同的备选方案。
