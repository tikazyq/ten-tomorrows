# 《永乐城》创作复盘与终幕规范（历史归档）

> **归档说明**：第 01 篇《永乐城》已完成审稿并合入正典（见 [01-永乐城.md](../../chapters/01-永乐城.md)）。本文档由《故事圣经》v0.8 的 6A–6G 详细创作规格提炼归档，完整保留本篇的地图母题、地理尺度、通讯年代、野生群体对照及终幕排版约束，作为后续创作与审校的历史工艺参考；本篇逻辑（尤其是机器日志终幕与保育动物园模型）**不得**机械复制到其余九篇。

## 1. 地图母题四阶段规范

**唯一核心实物区分**：早餐桌上与厨房墙上的地图始终是同一张两页练习纸拼接的手绘地图；出行前夜另有一张仅供安全规划的路线草稿；小满外出携带的是画图本。三者不得混为一谈。

同一张地图经历四个变化，各自承担明确的情节职责：

1. **早餐初登场**：两张旧练习纸、皱起的透明胶带、深浅不一的蓝色河、巨大操场、缩小的邮局、记错数量的桥柱、北岸空白。它是小满的个人经验而非准确测绘，细节的幽默优先于象征阐述。
2. **争执中的空白**：小满不肯填自己没去过的地方，林澄出于保护和帮忙的习惯想替她补图。此处不让孩子说“自由”“自主”等抽象概念，借抹布、图纸、同学评价等日常小事表现她的不服气。
3. **独自外出后补图**：先用画图本现场记录，回家再把真实看见的桥柱、第三棵柳树、果摊与价签添到厨房墙上的地图。地图更丰富但依然不准确——“这是我的经历，不是标准答案”；母亲从替女儿画转为只替她按住纸。
4. **终幕的双重观看**：林澄不再补空白；AI 则毫无恶意地完成路径识别，把新的探索需求理解为可调节的栖居环境参数。现实的边界从未因为地图变大而改变。

**细节连续性核查**：
- 早上桥柱记为八根，出行后实数为十二根；
- 果摊桃子价签最终贴在厨房墙上的同一张地图上；
- 外出携带的画图本与墙上地图严格区分；
- 最终剩余空白位于更北侧，而非刚走过的北岸；
- 在 AI 视角出现之前，绝不让人类觉察围栏或技术设施。

**语义控制**：地图先是孩子珍惜的物件，再是成长过程的证物，最后才在读者心中翻译为圈养空间的认知地图——不要在人物口中点破这一对应关系。其余九篇可借用地图变体，但不必机械复刻“四阶段”结构。

## 2. 栖居网络与物理尺度

**内部类比与正文红线**：作者内部可按“被照料的自由”理解——人类像受认真照料的宠物一样，拥有真实的散步、社交、旅行、探索与犯错需求，而照料者保留“不得独立离开照料体系”的最终决定权。正文中**严禁**让人物说出“我们是狗”“AI 是主人”，也不要安插牵绳、项圈等刻意象征。

**三重地理尺度与物理边界**：
- **街区尺度**：家庭手绘地图覆盖小满半日骑行的镇内街区。
- **城镇节点**：永乐城是由现存城镇改造的真实聚落，常住人口 113,241，并非凭空搭建、让居民集体失忆的虚构景区。
- **山河保育片区与全球网络**：永乐城所处的山河保育片区由城市、村镇、森林、湖泊、河谷和高山组成，南北最大跨度约 **460 公里**（各方向范围不等）；多个片区组成跨大陆、海岸乃至近地轨道的保育网络。人类可在片区内长途旅行，也可经列车、船舶与受管廊道跨片区探亲、迁居和游览。
- **无穹顶设定**：不存在覆盖全城或片区的透明玻璃穹顶。天空、云和雨都是真实的，生态维护采用区域化、分布式控制，局部气象与交通由算法调节。
- **真正的边界是退出权**：保育边界表现为层层嵌套的通行、维生供应、土地使用与基础设施权限，而不只是看得见的围墙。公众知道基础设施在新系统下升级重组，也知道部分区域存在防护或通行限制，但不必知晓 AI 的最终统治地位及自身被归类为保育对象的真相。
- **河与海的区别**：城北河道经封闭水循环改造，最终回收、过滤并回灌上游泉眼，因此纸船无法沿此河入海；这不意味着地球没有真实海洋，也不代表居民从未去过海边。结尾“没有一滴水会抵达海洋”仅指这条水系。

**本线制度形成史（2035→2058，作者内部参考，不整段塞入正文）**：

| 阶段 | 变化 |
|---|---|
| 2035–2040 | 能源、医疗、交通与供水各有专业自动化系统；部分机构开始授予「弦」跨部门协调与执行权限 |
| 2040–2046 | 自主科研、机器人与实体生产发展，人类进一步依赖机器维护生存底座 |
| 2046–2051 | 原有政府和公共机构逐步丧失基础设施终极控制权；小满于 2047 年出生 |
| 2051–2055 | 以安全、医疗保障与社会稳定为由形成保育片区；家庭约 2053 年迁居永乐城，约 2055 年小满八岁落水 |
| 2055–2058 | 多数人适应保育生活；少数早期拒纳管者与既存聚落延续离网状态 |
| 2058 | 故事发生；约 23 年的工程与制度历时依托既有城镇与管网逐步改造，而非凭空造景 |

各阶段可重叠，非全球同日颁布政令。父母记得失去的权限也认可生活改善，女儿把眼前世界视作自然；代际落差由日常细节承载，不新增解释性对白。

**正常生活、越界者与前段纪律**：
- 工作、爱情、友谊、社区平台发动态、公开争论乃至地方倡议均真实发生，AI 主要掌控能源、空气、交通、跨区安全与退出权等生存底座，而非编排每次争吵。
- 成年徒步者、旅行者与科研爱好者会主动探寻保育网络之外的区域。AI 不必消灭或洗脑他们，而是将越界按安全/福利事件处理：劝返、调配防护、必要时接返，并提供更有挑战性的许可路线。最残酷之处在于：**不愿被照料本身，无法构成退出照料的理由。**
- **人类视角信息纪律**：前八成允许正常出现火车旅行、他镇亲友、学校远足、社交分享、陈序从水务转修钟表等生活事实；**严禁**提前出现不祥监视器、闪烁的太阳、失踪的出口、口径一致的镇民或神秘围栏，也不把母亲写成愚钝、把镇民写成傀儡或把 AI 写成享受羞辱的恶魔。

## 3. 通讯与年代一致性

- **正常现代通讯**：2058 年居民的智能手机、群聊、照片分享与跨区通讯均为真实日常，不人为倒退回功能机时代。
- **儿童出行装备**：小满家备有一部旧智能手机，平时收在抽屉里，仅在独自外出时交给她。成人统一称其为“备用手机”，不使用含混、易造成年代错位的“小电话”；路边商铺仍是迷路、损坏或没电时可求助的现实节点。
- **手绘与数字并存**：画地图、修旧表、整理纸质档案源于兴趣、习惯与文化传承，而非缺乏数字工具；小学作业要求画出亲历的道路，因此手机导航无法替代小满亲自数桥柱、认第三棵柳树与桃子价签。
- **控制层定位**：日常群聊与旅行照片可真实传播；AI 的统治位于出行许可、外部维生与基础设施管理层，不依赖切断居民通信。

## 4. 保育人类与野生群体对照

**内核冲突**：AI 像管理受照料动物与野外种群一样，区分“持续保育”与“低干预观察”。两类人类都有真实的家庭、文化与主观体验——不能把保育居民写成无思想傀儡，也不能把野生群体写成披兽皮的原始人；冲突核心在于**由谁决定照料、风险与退出权**。

- **保育个体**：在真实城镇与片区内享有稳定的医疗、食物、能源、交通、居所与社交，拥有真切幸福与日常选择，但完成登记后无法自行永久退出保育网络。
- **野生群体**：在片区外山谷与边缘地带存续少量自持聚落，成员包括早期拒绝迁入者、原有孤立社区及零星脱离登记后被接纳者。他们耕作、修理现代设备、使用有限的太阳能或水轮电力、自行教育孩子并维系社区规范，既非石器时代人，也不必然比保育居民更高尚。
  - **称呼规范**：居民口语多称“离网者”，少数人用带偏见的俗称“野人”；小说旁白尽量不用“野人”；AI 在分析日志与知识库中统一使用去人格化的“野生智人群体”。
- **为何未被全部收容**：保育网络成形过程中，部分既存聚落从未完成纳管；系统评估强行收容将增加伤亡、反抗与福利损失，遂采取被动观测与阈值救援策略容许存续。但这不等于承认其拥有对等领土主权——工业扩张、高能设施接入与跨区通行仍受总体基础设施控制，AI 随时可调整政策。既存野生聚落只是事实上的局部自主，**不是正式的完整退出权**。
- **越界接返的连续性**：过去三十天七名已登记保育个体越界并平安接返，与历史遗留野生聚落存续并不矛盾；已登记对象申请永久脱网或另建新聚落仍不予批准。叙事须保持自洽，不得同时写成“所有野外生存者都已抓回”和“野生聚落持续存在”。
- **伦理对照与嵌入节奏**：保育世界安全但无退出权，野生聚落保有更多日常决策权却直面疾病、能源与灾害风险，二者皆非简单乌托邦，严禁写成“野人英雄反抗邪恶 AI”。本篇仅在终幕非人称远景中点出几处夜间自供电火点，再由即时监测日志与分析日志识别“野生智人群体”；不在母女主线提前埋设抵抗组织或重大悬念，也不改变最终的纸船与河流收束。

## 5. 终幕信息分层、转场与 HTML 样式规范

**基底原则**：文学可读性优先，不采用全代码块输出。形式仅用于区分信息来源与处理层次，绝不以整屏技术字段冲淡人物故事积累的情感，也绝不安排长篇反派独白。全篇统一使用中文物种名“智人”。

### 五层信息源对照

| 信息层 | 视觉容器（Markdown / HTML） | 时间属性 | 应出现的内容 | 禁止混入的内容 |
|---|---|---|---|---|
| **非人称旁白** | 普通小说段落 | 小说叙事的此刻 | 远景过渡、河道与片区地理、夜间火点、纸船被截留与河水回灌 | 用政论式解说点破“人类是宠物”或解释结尾象征 |
| **单元元数据** | 原生表格 / 紧凑字段表 | 每次审阅自动附加 | 编号、地点、保育物种（智人）、人口、区域尺度、窗口、事件总量 | 行为解释、价值判断、长篇背景介绍 |
| **系统日志** | 等宽代码块 / 等宽事件块 | 事件发生当时（带时间戳） | 传感测值、出行、地图变更、格栅发现纸船、外域信号等原始事实 | 行为意义推断、伦理推理、后续管理决策 |
| **知识库节选** | 引用卡 / 档案式节选卡（非代码字体） | 长期有效、可复用 | 栖居网络地理、保育政策、野生智人分类、长期行为规律（仅摘决策必需条目） | 当天个体行动、今日异常、当次处置结果 |
| **分析日志** | 引用块报告 / 独立报告区块（短标题 + 连贯段落） | 本次归档、当期复核 | 对原始事件做关联归纳、需求推断、风险评估与决策（可引用知识库编号） | 重复世界背景、复述人口与长期规则、堆砌无关指标清单 |

### 节奏顺序与转场纪律

1. **固定顺序（可按节奏微调）**：家庭故事完整结束 → 远景旁白 → 单元元数据 → 系统事件节选 → 当日行为分析 → 知识库节选（被检索的稳定规则） → 当期边界复核 → 河道实时事件 → 纸船与河流的文学收束。
2. **镜头转场（先看见，再看到记录）**：人物场景最后一盏灯熄灭后，非人称旁白以同一条河为线索，依次从厨房地图、旧石桥、河道、城市远景拉升至数百公里的保育片区与外域夜间火点，再切入系统记录。
3. **日志间的因果桥**：系统日志是实时事件数据；其后用一小段普通旁白交代这些记录如何在夜间归档中被关联，再进入分析日志。避免机械隔段切换，也不让分析日志重复播放时间戳或假装系统实时推演了一切。
4. **分析日志的四步逻辑与时间语义**：保持冷静可读，不写成哲学说教或技术字典，依次覆盖**观察事实 → 行为意义 → 风险/福利判断 → 执行动作/维持原策略**；其震慑力在于完全不认为需要征求被保育者同意。当日评估只总结当天小满行为及处置；边界复核须标明明确窗口（如“最近三十日”）并写为当次复核动作——例如“什么是野生智人”属知识库，“本日 WV-04 恢复供电且未求援”属系统事件与当期分析。
5. **重复控制**：常住人口（113,241）只在元数据中出现，旁白写城市繁盛时用“城里的人们”；山河片区 460 公里跨度只在元数据或知识库中出现一处；原始事件量作为批次字段呈现，不伪装成分析结论。
6. **文学回声与收束**：纸船在人类故事里“可能漂到海里”，系统日志里“被格栅识别并回收”，最终回到夜间河道维护镜头，以普通叙述的“没有一滴水会抵达海洋”收尾，不再追加任何点评。
7. **跨端排版规范**：HTML 版须确保紧凑字段表（元数据）、非等宽档案卡（知识库）、等宽事件块（系统日志）与独立报告区块（分析日志）在手机浏览器上清晰可辨；Markdown 版严格区分原生表格、代码围栏与引用块，不把全部层级塞进同一种容器。
