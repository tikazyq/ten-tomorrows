# 《十个明天》｜审稿标准与交接流程 v1.2（v0.8 配套）

## 两道人工审核闸门

**A. 结构方案**
- 不靠作者解释，读者是否明白主角的迫切目标？
- 阻碍是否来自具体的行动、关系与制度，而非议题需要而出现的反派？
- 结局是否经过因果铺垫，并与其他篇章在形式上区分？
- 世界机制、能力和权力边界是否自洽？
- 起点至当下是否有足够的工程、制度与社会适应时间？人物年龄是否按出生参照计算，远未来的身份与记忆是否有来历？
- 是否列明必要技术、未成熟或受限能力、控制权归属？数字篇是否区分外部历时、体验、暂停与记忆，并声明科幻前提？
- 与《永乐城》是否具有可辨识的美学差异？

**B. 完整初稿**

| 维度 | 核查问题 | 否决信号 |
|---|---|---|
| 人物 | 有独立欲望与局限吗？ | 只为朗诵观点存在 |
| 因果 | 场景会改变下一场的条件吗？ | 突然解释世界代替情节 |
| 对话 | 人物年龄/职业口吻可信吗？ | 人人说同一种金句 |
| 情感 | 先让人关心人物再理解主题吗？ | 靠惨剧和概念堆砌 |
| 科幻 | 技术和制度能自圆其说吗？ | AI 能力随情节任意变动 |
| 差异 | 与其他九篇互补吗？ | 篇篇同一反转和日志 |
| 克制 | 信任读者自行理解吗？ | 结尾直接解释哲学结论 |
| 连续性 | 起点、人物和时间线自洽吗？ | 跨宇宙传信或抹平悲剧 |

## 审稿流程

1. Agent 提交结构方案，主编先审；未经批准不产出全文。
2. 完整初稿由另一名审读者只读审阅，独立提交问题清单，不能直接覆盖作者稿。
3. 主编根据问题清单文学统稿，进行跨篇人物/设定/情节核对。
4. 作者从读者体验作最终审核：人物真实吗？愿意读完吗？结尾是否自然？
5. 已批准文本才进入 `chapters/`；每次修改保存历史，不能静默覆写。

## 标题审稿

标题应指向本篇具体事件或意象，阅读后获得新的情感意义，而非抽象哲学概念。

- 《已办结》暂定：必须有真实结案过程及未解决的个人后果。
- 《未写的答案》暂定：先提出两套不同因果机制及备选标题，不能为迁就标题强造“已故学生考卷”情节。
- 目录以 [目录与标题状态](../目录与标题状态.md) 为准；v0.8 故事圣经已同步当前暂定标题。
