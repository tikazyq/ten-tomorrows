# 《十个明天》创作与审稿规范

## 权威输入顺序

1. [目录与标题状态](目录与标题状态.md)确定篇名和当前进度。
2. [故事圣经](../canon/story-bible.md)确定共享人物、时间、技术和伦理边界。
3. [《永乐城》已审正文](../chapters/01-永乐城.md)是人物真实性与文学质量的基准。
4. 本规范约束创作、审稿与交接。
5. [章节任务书](../briefs/)给出具体情节、边界和交付要求。写作者只处理分配到的篇目。

## 文学与文风

- 写一篇能独立阅读的小说。人物有具体欲望、职业、过去、缺点和社会关系，让行动与选择承担主题。
- 正文由 Neon 执笔，采用**市井口语腔（Voice C）**。长短句错落，少解释、少收束，旁白克制，不盖过人物。让年龄、职业和关系决定口吻。
- 儿童用当下年龄会用的称谓和表达。三人以上对话要明确归属，可用推动情绪的动作标明谁在说。
- 叙事形式由冲突决定。关键发现要在事件里铺垫，避免靠一份突然出现的秘密文件揭开全部谜底。

## Gate A · 结构方案

每篇提交以下材料，经主编交叉审读、作者人工批准后，才可写完整初稿。

1. 约 100 字核心命题，交代主角的目标与障碍。
2. 800–1200 汉字结构方案，交代时空、关键决定、代价与结尾。
3. 6–8 张场景卡，每张写明人物目标、实际阻碍、关系变化和可见物件。
4. 设定假设及最多 3 项需要主编裁定的问题。
5. 连续性说明，列出起止时间、人物年龄与代际、必要技术、未成熟或受限能力、控制权归属与形成历时。数字心智篇另列外部历时、体验时间、暂停与记忆，注明主观体验和身份连续性的科幻前提。[技术设定与证据边界](../research/技术设定边界.md)

审读时检查主角目标是否迫切，阻碍是否产生于具体人物与制度，结局是否经过铺垫，技术和制度是否有足够时间形成，以及本篇是否有独立的审美和情感落点。

## Gate B · 完整初稿

交付约 4000–6500 汉字初稿，篇幅服从故事。附 200–400 字连续性说明和自检，指出可能说教、重复、失真或结尾乏力的地方。

| 维度 | 核查问题 | 否决信号 |
|---|---|---|
| 人物 | 人物有独立欲望与局限吗？ | 只为朗诵观点存在 |
| 因果 | 场景是否改变下一场的条件？ | 突然解释世界代替情节 |
| 对话 | 年龄、职业和关系能从口吻听出来吗？ | 人人说同一种金句 |
| 情感 | 读者能否先关心人物，再理解主题？ | 堆砌惨剧和概念 |
| 科幻 | 技术、制度和授权是否自洽？ | AI 能力随情节任意变动 |
| 差异 | 本篇与其余九篇是否互补？ | 反复使用同一反转和日志 |
| 克制 | 结尾给读者留下自行理解的空间吗？ | 直接解释哲学结论 |
| 连续性 | 人物年龄、代际、权限与时间线自洽吗？ | 跨宇宙传信或抹平悲剧 |

由另一名审读者独立提交问题清单，保留作者原稿。主编按清单统稿并跨篇核对，作者从阅读体验作最终人工审核。用对应的章节 Issue 跟踪问题，用 PR 提交方案、稿件、审读意见和主编改稿，保留版本历史。批准须在 Issue 或 PR 中明确记录。已批准的小说正文才进入 `chapters/`，只有仓库维护者明确批准后才可标作 `approved`。

## 跨篇检验与禁止项

- 2035 年 11 月是「弦」的多技术汇合与自主授权分歧点。小满 2047 年出生，2035 年不得出场。按圣经第 5A 节核对年龄；远未来用有来历的后代、新人物或数字心智，不能默认为原始家庭延寿、上传或复活。
- 各篇是独立时间线。不得以梦境、模拟、平行宇宙救援或通信抹去已发生的决定和悲剧。不得把科幻前提写成已获实证的事实。
- 《永乐城》已经使用孩子手绘地图、母亲放手、纸船、水循环、机器日志和保育／野生智人对照。核对各篇人物行动、物件、反转和末场，避免重复使用这些组合。其他时间线沿用永乐城特有的制度或地理，须有情节依据。
- 第 02 篇的最终治理权不可撤销；第 03 篇无人拥有最终纠错权，正文保留「已办结」回执。第 04 篇由人类掌权者承担责任。第 05 篇的工具权限可撤销。第 08 篇从家庭最后的相处写起，勿用突然出现的系统日志解释灭绝。第 10 篇保留公共分歧；第 11 篇待统稿再定末场及最后一句。
- 小说开头不标示所对应的 AI 结局类别。不得擅改其他写作者的成果或覆盖已审篇章。共享正典的变更须有独立 Issue、PR 和人工审稿批准。
