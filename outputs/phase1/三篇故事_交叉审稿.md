# 三篇故事交叉审稿

第一阶段 · 结构修订待人工审阅。三组场景沿用本 PR 的人物与已有结尾，按 [v0.8 时间线候选稿](https://github.com/tikazyq/ten-tomorrows/pull/14) 重算年龄。每篇开头的日常试写可单独阅读。

| 篇目 | 哪些原情节还成立 | 哪一步要换 | 场景里的检验 |
|---|---|---|---|
| [《完美的一天》](02_完美的一天_结构方案.md) | 母亲想撤回女儿的报名，晚间拿着自己投过的赞成票要求交接 | 探测取样交给机器。成年小满陪周姨挑一处用得顺手的歇脚点 | 同一个市政席可以改接车点，也可以拒绝让居民接管下一轮试走。末场周姨坐在自己挑的位置上，看见走廊那头的林澄招手 |
| [《已办结》](03_已办结_结构方案.md) | 近校空桌、换掉晚班、外公取回钥匙都成立 | 路网及时报告封门。外公身体力行试的是改道后的接驳，AI 已能算出近校的安排 | 近校可以暂留桌位，开学从入校起由谁接手孩子，要有连同经费一起生效的授权。再找一位热心人也不能代签 |
| [《最后一个生日》](08_最后一个生日_结构方案.md) | 黄桃蛋糕、站台改派和分掉留给明天的那一份成立 | 小满十七岁，能换值日、给熟人带一壶水。乘车去向随车更新，成年人负责商量怎么安置返程的人 | 她还了水壶，梁婶问起糖水，邻居间的来往直到当晚仍能兑现。远方有人继续养育下一代 |

## 逐篇意见

**《完美的一天》。** 小满为何亲自进洞，周姨坐下就说得清。家属新提供的老回执背面有一句未入档的题记，林澄的发现确实能改变安全复核，所以女儿得到了母亲一次管用的帮助。表决前让居民出示一个有人当班、有人愿意接过责任的实际方案。只要着重写一次签发及当日生效的新预约，场景已经说清谁拥有最后决定权。

**《已办结》。** 教育落到一只一起抬的纸袋和一顿有老师照看的午饭。周蕙愿意为老人们留在桌边，换掉晚班的损失才有工资以外的分量。近校暂留位依原候补名单递补；个案若从已确认的北站转入，则涉及两校间的照护交接。这层区别要在回执生效前让读者看懂。办结放在倒数第二场，外公和果果有最后一句家常话。

**《最后一个生日》。** 一座仍然能上课、借壶、换值日的图书馆，让返回的乘客有了可认的面孔。水台按时报了可用，陈序弄湿裤脚才把梁婶的壶修好。站里的人替安置双方提出异议，货车最终开去哪里，家属也同时得到答复。现场决定的是当天哪些人还有床位。末场前的短前瞻才跨到别处，写那些多活了几十年、也养大过孩子的人。

## 各线人物知道什么，场景怎样交代

分歧前的共同历史见 [PR #14 的 v0.8 时间线候选稿](https://github.com/tikazyq/ten-tomorrows/pull/14)。

- **02** 林澄用过上门照护，也记得试用期满可以交回管理权。她以为居民排好轮值、有人肯补班，就能照旧办理。让她带着一张曾经有效的到期交接单和今天的轮值表回来，由市政席当面决定谁签发下一轮预约。
- **03** 周蕙在家已看到试排，仍以为能找到一位可以签字的人。果果从小就习惯按全区名册分配，只关心能否和小叶同校、外公能否来接。让许岚调出从前签完当天就生效的改校个案，再把今天的空桌、照护名册和结算记录摆在一起。
- **08** 陈序年轻时亲手验过管线、签过交接，记得气候工程曾帮市民度过几个夏天。他从改派的运输单上看得出这车设备一走，哪些人当天没有床位。其他聚落能撑多久，由后来的短前瞻交代。

## 十九张场景卡逐场复核

| 场次 | 原写法里值得追问的地方 | 本轮处理 |
|---|---|---|
| 02-1 | 公共档案还要人挨个认脸，老人还要有人替她调设备吗？ | 常规识别已经完成。只留周姨辨认老工友的私人记忆，以及她戴新耳模来人多处试一试的经验。 |
| 02-2 | 成年人撤回报名，要由紧急联系人带材料到窗口吗？ | 林澄当面开口，市政席只接受本人撤回。她能贡献的是家属留在回执背面的新证词。 |
| 02-3 | 安全员为什么要亲自查找同名地点？ | 系统呈现现有巡检证据，人要对新题记仍有疑点时开放哪一段负责。 |
| 02-4 | 移两把试用的椅子要按指印吗？ | 直接摆了就坐，晚间听实际使用者的意见。 |
| 02-5 | 居民接管公共服务，只等于自己排班、记笔录吗？ | 排班与记录可自动做。居民要决定少接一组、给慢行者多留半天，并问谁愿意补班。 |
| 02-6 | 散会为什么还拿纸、还要等人？ | 纸是林澄特意留下的副本。周姨等的是想一起回家的街坊。保留无人接送和彼此招手。 |
| 03-1 | 出餐与授课都已能自动完成，为什么还去养老中心和学校？ | 冯伯要等自己捏的包子，果果要和小叶一起抬梨。两处保留有来往的人，基础学习在家也能完成。 |
| 03-2 | 门到门陪送能否化解两段接驳？ | 有这项服务，费用却超过这家人靠固定晚班多挣的钱。免费线上的坡要由外公亲自试。 |
| 03-3 | 新路况是否还要家长递交、由招生员重录？ | 在家已能看试排。周蕙去近校，是要当面问谁能接下女儿。 |
| 03-4 | 把纸质午餐名册换成屏幕就能解决问题吗？ | 配餐可自动核对。周蕙看见有人蹲下来陪打翻碗的孩子。果果入校的第一刻，也得有获准接手她的人。 |
| 03-5 | 为何要靠许岚跑两校传证明？ | 三方可同时调阅。看见同一结果以后，各方仍缺把学籍、照护和经费一起转移的权限。 |
| 03-6 | 智能排班能否让周蕙提前一个半小时走？ | 她领的是固定陪一桌老人到散席的班；同事接下整桌，她换成能及时接孩子、工时浮动的白班。 |
| 03-7 | 一把家门钥匙、一张乘车卡都要成为六岁孩子的日用品吗？ | 钥匙开外公裁缝间的老木门，代表回家试裙子的约定；响扣系回书包。 |
| 08-1 | 换到图书馆以后，还要照常听课、交同一张图吗？ | 各自的基础学习可以随人迁移。两位伙伴到场互试玩具，让候车的孩子带走拼片。 |
| 08-2 | 管网还要靠退休工程师记得一个旧地名才能恢复供水吗？ | 饮水台自行报修并报告恢复。父女替抽不开身的人接水，陈序修好一只漏水的壶。 |
| 08-3 | 调拨情况得赶去站台、接过两张纸才知道吗？ | 两地和家属都能收到结果。值守者提出例外，陈序留在站台陪一位母亲等女儿。 |
| 08-4 | 林澄需要重新点一遍返程乘客吗？ | 名册随车更新，家属到场接人。小满替梁婶腾出手，再把壶递给她。 |
| 08-5 | 找床位、借设备是否依赖私人通讯录？ | 空间与余量对安置点可见。还须邻站愿借、返程者愿意同住，本地的承诺真能多争取几天。 |
| 08-6 | 生日蛋糕、纸碟和留给明天的一块是不是年代错置？ | 保留。写歪的字是陈序多年的手迹，小满推回纸碟也是这个家庭自己的动作。 |

## 连续性核对

- 三条独立历史从 2035 年十一月分歧。02 暂取 2073 年，为保留原结构中二十六岁的小满，较 v0.8 建议锚点 2068 年后移五年，仍在该篇窗口内。林澄约五十八岁。
- 03 暂取 2054 年，果果六岁，使用独立家庭。北站按七月名册录取，厂门随后关闭并及时更新路网；变更路网与改动已生效名册由不同机构负责。
- 08 暂取 2064 年立夏前，承接 2047 年出生参照与生日季节。小满过十七岁生日，父母约四十九、五十三岁。2107 年只作全球终局的候选年份，与这家人最后的生日隔四十三年。
- 三篇的制度也不同。02 居民找到了愿意接班的人，现任管理者拒绝交接。03 当事各方赞成一件事，却缺了能签发例外的人。08 邻居还能互帮互救，跨区的去向已经另有安排。[题名与因果](标题与因果评估.md)
