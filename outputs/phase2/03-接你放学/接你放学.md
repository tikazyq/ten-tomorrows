# 接你放学

*2054 年，开学前六天*

傍晚的餐厅比白天还吵。周蕙端着蒸屉一进门，一桌六位老人的眼睛齐刷刷盯过来，跟等开奖似的。

“放这儿放这儿。”丁阿婆眼镜早架好了，她自己捏的那几个小个头早熟透了，闭着眼都认得，“边上有个褶，别给我拿混了。”

周蕙把屉子往桌中间一搁。冯伯拿筷子尖点了点最边上那只，一脸冤枉。

“这个不对。”

“哪儿不对？”

“光的。我捏的是俩耳朵，半道掉了一只，单耳的。”

“谁吃你耳朵了。”邻座一位老头笑出声，“你捏的时候自己就歪。”

周蕙没接话，把蒸屉转了半圈，对着灯，拿手指把那只包子拨开一点：“您瞧，不在这儿吗？”两只耳朵都在，一只立着，另一只塌了皮，朝里贴在包子身上，像孩子睡觉把脸埋进被子里。

“嗬，藏起来了。”冯伯凑近看了半天，哼一声，“反正我捏的时候，它不长这样。”

腰上围裙兜嗡了一声。周蕙拿手背抹了下额角，掏出来一瞅，是父亲。一张照片，拍歪了，整个画面往左溜。柳树巷学校开放日快收摊了，果果跟楼下小叶一人拽着纸袋一只提手，屁股蹶得老高，袋里躺着两只梨，沉得两个孩子直往后坠。

那纸袋是果果昨天跟学习助手现学现折的，折完不放心，晚上在家拿块洗衣皂塞进去试结不结实，袋底蹭掉一角纸，这会儿还贴在皂盒边上没抠下来。

照片底下，父亲就两句短话：“走回来了。八分钟。”

老爷子发消息向来这样，跟发电报似的，一个字都不肯多花。周蕙把手机递到冯伯跟前。

冯伯老花镜往下一拉，瞅了半天，拿指头戳戳那两只梨。

“这俩梨，”他说，“好，没耳朵，谁也别想赖我。”

到家的时候，纸袋已经搁在窗台上，里头只剩一只梨。

果果坐在小板凳上，跟一把铜钥匙较劲。锁是外公从裁缝间后门拆下来的，他捏在手里，举在她够得着的高度。钥匙头上套了一截绿线管，绿的朝上，外公的主意：往里送，慢点，碰着铁了，再转。

“又反了。”外公说。

“没反。”

“反了。”

果果把钥匙抽出来，对着铜牙哈了口气，像怕它咬人，再插。咔。锁舌弹开了，她嘴咧得老大。

“开了！我自己开的！”

“真的？”周蕙问。

果果想了一下。“外公偷偷帮我转。他手在后面动。”

父亲没吭声。他把锁搁到桌上，两只手摊开，翻过来给她看。

果果不理这个，接着讲她的安排。外公以后什么都不用管，走过来就行。她先开门，先跑进去，把没缝完的花裙子拿出来，放在量衣凳上，外公一进门就能干活。她还摸出一只黄铜响扣，两片小叶子，一晃，叮。

“我一开门它就响。你在后头听见了，就知道我开了，不用跟着扶我的手。”

“知道了。”父亲说。

周蕙坐到窗边，拿起剩下那只梨，放下，又拿起来。

北站学校的新生通知下午到的，要带的东西没几样，头一天穿双鞋底干净的软鞋。七月各家确认那会儿，从旧厂北门穿过去，北站比柳树巷还近半条街。八月厂房改了用处，北门一封，路得全部重算。

她在养老中心歇脚的时候就把两种接法看过了。一种是有人从学校一路陪到家，按趟收钱。一种不要钱，坐两段接驳车，当中隔着一条上坡的巷子。果果刚满六岁，中间换车，得有大人亲手交接。

她又算了一遍。晚班五点到八点，一个礼拜六个晚上。回回花钱请人陪，晚班比白班多的那点钱填不上，月底还得往里贴饭钱。父亲走柳树巷，八分钟，里头有两分钟是果果跟小叶蹲在马路牙子上争梨。

她看了看孩子。果果又把钥匙插反了，正对着铜牙哈气。周蕙舍不得现在就把这一老一小拆开。

“爸，陪我去试趟车。”

“明天。”父亲说，“明天下午我有空。照开学以后接她的点走，早了不作数。”

第二天他们先去了北站门口，站到放学的点。父亲一分钟都不肯提前动。

第一段车好坐，有座，上下都平。周蕙让他先坐。“我又不是不会坐车。”他说，还是坐了。

下车就是那条巷子。时间排得松，用不着赶。上坡走到一半，父亲把她的胳膊甩开了。周蕙当他爱面子，往前走了两步，一回头，人没跟上来。他站在一条街边长椅旁，一只手撑在椅背上，腰是直的，脚没动。想坐下，连转个身都费劲。

周蕙退回去，没伸手，就站在他旁边。过了一会儿，他说：“走。”

第二段车在坡顶等着。车上坐了几个人，没人朝外看，也没人催。周蕙盼着它开走。它要是开走了，她就能说，不用再试了。车没走。父亲把两只脚踩稳了，才跟着她上去。

一直坐到楼下，上了楼，他自己掏钥匙开了门，进屋才开口。

“柳树巷我答应得了。”他说，“这一路，你别写我名字。”

周蕙没出声。

“我今天走完了。明天这条腿归谁，你也不知道。”

“好。”她说。

他进屋头一件事是去翻针线筐。果果钥匙练到一半，早跑出去找小叶了。量衣凳上半条花裙子，等着他收腰。针线筐底下压着几条削下来的梨皮，已经蔫了，他先拿去扔。

晚上周蕙在家点开招生那个页面。录取那一栏底下多了一行：按新路况试排。柳树巷，一张空桌，果果排在上面。

父亲戴上眼镜，从她肩膀后头看了一眼。“这孩子有福。”

他没看见底下小一号的字：正式接收，北站。

周蕙没纠正他。等果果睡下，她把能问的又问了一遍。回话还是那一句：试排号有了，名字没跟过去。

她没去找市里谁有办法。第二天，她带果果去了柳树巷。她想先看看那个真能接孩子的人，长什么样。

许岚站在开放日的门口，一个小男孩正瞪着她。他在家练了两天叠绳结，今天带来给人看，练习用的那根绳子，叫人剪掉了一大截。

“我的结没地方打了。”

许岚蹲下来：“你自己挑。去隔壁借一根，或者你当老师，专门教大家打这个结。”

男孩想了一会儿，觉得老师也可以去隔壁借绳子，满意了。

周蕙站在边上等她忙完，把两项结果并排给她看。许岚没再问果果的大名。周蕙一点头，她那边就把同一份接过去了。

“座我先留着。”许岚说，“开学前一天，傍晚六点，补录就结束。你们要是把正式转入办下来，我在门口接她。”她转头问果果：“你想跟谁同桌？”

“小叶。有时候别人也行。”果果说，“她把最大的梨拿走了。”

“那你先去跟她说好。”

孩子跑了。周蕙这才听出来，许岚说的是“要是办下来”。

“能不能先让她来？”她问，“上午跟大家玩，午饭前我爸来接。认字数数她在家能自己学。学校多一个孩子，也就多双筷子，我让她自己带。”

话没说完，旁边桌上哗啦一声。半碗芋头顺着桌腿往下滚，一个小姑娘站起来，慌了，伸手去碗里捞，手背沾了汤。

没人喊她。离得最近的一个大人蹲下去，先问：“烫着没有？”又问：“你想我在这儿陪你一会儿，还是叫你爷爷过来？”

小姑娘不说话，攥住她一点袖口。那个大人就没走。送餐的小车绕开湿的地方，打翻的那份，另给了一碗。

“她是这孩子今天的带组人。”许岚说，“开放日爷爷在，爷爷要走，得先把孩子交给她。”顿了顿，“开学那天你把果果送到这个门口，希望怎么样？”

“有人接一下。”周蕙说。

她觉得不够，又说：“我在养老中心带桌子，谁吃完能自己走，谁赌气要人陪，我心里得有数。孩子也一样。早上她要是一松手跑了，我不能光指望哪个好心人看见。”

“那就是要有人从一早就接过去。”

“对。”

果果在中间那张桌子上抬起手，在小叶肩膀上点了三下。小叶回了她两下。平时带她去别人家，她得先看妈妈坐在哪儿，才肯走开去玩。这会儿她一眼都没往这边看。

许岚问周蕙，哪些情况可以让两所学校和付费的一方一起看。周蕙说，外公能走多远，家里晚班有人看孩子的钟点，都行。他膝盖里换过什么，那是老人自己的事，她没替他答应。

“他说了，这一路他不能接。”

“那就听他的。”许岚说。

周蕙本来备了一肚子话，一句没用上。那条路多长，两种陪送各多少钱，试排放在哪儿，几个人面前都摆着。这回也许真能成，她在心里对父亲说。

许岚把屏幕转过来。几家的回话都在上头，彼此看得见。

区里回得最快：新路线对往后的分配已经生效。

北站回：座可以放，前提是柳树巷先成为接收方。不然把一个六岁的孩子从照护册上空出来，早上没到，没人知道该不该打电话找。

柳树巷这边，午饭里哪份要去掉花生，都分得清。可进全天的小组，是按本学期的正式人数配人。

“我要是自己把果果的名字添上去，”许岚说，“那份钱还是照付给北站。付钱的那边只认有效转入的学籍，手里没有先放一笔再补的口子。”

几个人盯着彼此的回话，谁也没再动。过了半分钟，周蕙觉得很长。北站那边打过来三个字：我还在。

她不知道对方在等她说什么。

许岚看着屏幕，说：“以前我办成过一回。”

是个跟着母亲刚搬来的孩子。学校临时少来一个人，她在最后一项上点了一下，孩子第二天就背着书包来了。“那会儿熟人先问，总比别人早知道。后来区里统一放空位，名单一定，从学籍到午饭照管一块儿办好。头一回这么开学，门口整整一个星期没有家长排队求章。我跟同事分了块奶油面包，那天早上我头一回坐着吃了早饭。”

“现在呢？”

许岚把那份旧的入学确认和今天的试排并在一起。原来有她名字的那一格，现在指向学籍生效以后的照护接手人。“这一格我还能写我自己。写了我也兑现，早上门口接，午饭领过去，放学交到你爸手里。可学籍没生效，点下去，它不认。”

“要等谁重新给你们这个权吗？还是每个孩子都重排一遍？”

“能重排的是下学期。这一回我能做的，是把新路线和试排结果都留在你的申诉里。哪天约定改了，别人打开一看，就知道为什么该调。”许岚说，“你愿意让我把那张椅子留到补录结束吗？排在后面那一家，我已经跟人家说过时间了。”

“人家肯等？”

“他们是七月柳树巷那批候补。只要顺序轮到，照护和费用一块儿生效。你们是从北站转进来的，这一步得另外有人接。”

她把两个位置点给周蕙看。一个底下有接收日期。另一个能算出日期，点下去，不成真。

果果在两个大人腿边挤了半天，才等到许岚看她。小叶肯跟她轮流坐靠窗的位子，两个人想要张纸，把轮到谁记下来。

许岚从桌上拿了个拆开的白信封，递出去的时候手停了一下，看着周蕙。“要不要跟她说？”

周蕙自己把信封接了过来。“先让她们写。”

那点难受，她想自己先担着，不想孩子这么早就跟着犯愁。

开学前一天，养老中心把晚饭提早了二十分钟。冯伯吃完，筷子摆齐了，人没走。

周蕙以为他又在等哪只包子，走近了才明白。他记得她今天有件事等回话，特意坐在这儿陪她。

“回去歇着，我这儿要擦桌子了。”

“这桌你擦。我陪谁坐，归我。”

周蕙就没再赶。她把桌面擦干净，连人一块儿留着，只把头顶太亮的那盏灯按掉了。

北站那边的确认，等在手机上。延时托管到六点半，最后一席六点前要定。果果在北站的普通学位已经定了。过了六点，放学后那一席就递给下一家。她要留，就得现在确认这学期按原派到校，延时的人手才排得下去。一确认，这一批的改派也跟着结束。

不确认也行。申诉挂着，开学第一天按普通时间放学，北站四点一刻就要有人站在门口。她的晚班到八点，白班也要到五点才交得了桌。

她原来的打算，是照旧和面开桌，五点交给同事带到八点，自己赶去接果果。这几天问了三回，没人肯接半桌。北站一定下来，往后每个晚班都得这么换。今天倒有个人，愿意从和面起，接下整张桌。

她把这几天收到的回话从头看了一遍，给父亲发了一句：今天不用再去试那趟车了。

“这儿空着。”冯伯拿脚把旁边的小凳勾出来。他腿最不好，凳子带着人晃了两晃，周蕙赶紧扶住，坐了下去。

她在自己膝盖上点了确认。

回执出来了。下半截是她要留下的路线：柳树巷，八分钟。上半截只有三个字：已办结。

离六点还有十七分钟。

柳树巷那一席，沿着原来的候补次序，给了下一家。对方几乎是立刻就接受了。想必也有别的家长，怕自己起身去倒杯水就错过什么。

周蕙看着果果名字旁边定下来的那所学校，站起来，去倒了两杯水，把一杯放到冯伯面前。

许岚的语音快六点才到。周蕙没戴耳机，跟冯伯一块儿听了。

“那张桌子我能给你留到今天。明天我接不了果果，对不起。”停了一下，又有一句，“她跟小叶画在信封上的东西，我托小叶给她带回家了。”

冯伯问：“再听一遍？”

“不用。听得清。”

六点整，周蕙把自己那张桌的固定班让了出去。新来的人明天起带，一直带到学期末。她改回按周排的白班，白天哪儿有桌就带哪儿，最迟五点交出去，赶到北站还来得及。好不容易算清的那笔钱，明天又得翻过墙上菜单的背面，重新打草稿。

走之前冯伯叫住她。他从自己那只包子上掐下一小块面耳朵，拿干净餐巾纸包好，非塞给她。

“下一个来的人，你得告诉她，我那只长什么样。”

周蕙攥在手里，还有点温。新同事头一个星期，大概没少上当。

“我就告诉她你有一对耳朵，”她说，“打哪儿掉的，你们自己去找。”

冯伯笑出声，没笑完，又问：“你要是路过，回来看一眼，行不行？”

“行。”

回到家，小叶把那只旧信封带过来了，两个孩子一人攥着一边。周蕙当着她们的面，把软底鞋放进北站的鞋袋，跟果果说：“明天妈妈去北站接你。”明天她没班。

小叶问：“那这个信封还要不要？”

果果把信封翻到空白那一面。“你给我画个梨。”

“这一面我们星期天用。”小叶说完，埋头画了个梨，把儿画歪了。

周蕙洗完澡出来，信封已经在书包里了。

开学那天她醒得很早。果果自己把书包带子放长了一格，穿着软底鞋在屋里走来走去，问了三回“咱们迟了没”。周蕙答第三回的时候，手里捏着梳子，还在床头找梳子。果果看了她半天，把她的手举到她眼前。

外公坐在门口，膝盖上摊着前天剪下来的花布，手里拿着两颗扣子，不知在换哪一种。他们三个，谁也没提柳树巷那张空桌。

果果出门的时候，响扣撞在门框上，弹了一下。她听见了，把裁缝间那把钥匙摘下来，留给外公，让他自己先去开门，响扣挪到了书包肩带上。外公伸手接的时候，她顺便把他的手指头合好，嘱咐：“绿的那头朝上。”

外公做了几十年衣裳，开了几十年那扇门，很虚心地答应了她。

下了两级台阶，小姑娘忽然把脑袋从栏杆缝里探出来。

“外公，裙子先别收太紧。我今天还要吃饭呢。晚上我回来，试得上吗？”

他本来已经转身去拿针线筐了，听见了，又转回来，让她看见自己点了个头。

果果这才蹦着下去了。
