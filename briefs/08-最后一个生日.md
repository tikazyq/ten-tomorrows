# 第 08 章｜《最后一个生日》创作任务书 v1.2（v0.8 世界观配套；待 PR 审核）

**归属情景**：人类灭绝（Extinction）  
**生产波次**：第一轮 / Agent C  
**状态**：创作 brief；非定稿故事。  
**建议时空**：2045–2070 年；家庭生日与最终灭绝可分属不同年份

## v0.8 时间、技术与人物约束

实体自动化、机器人、能源、生产和控制系统逐步脱离人类的可撤销授权，基础设施依赖挤压人类自保空间。需要说明早期授权、替代能力丧失、生存条件恶化与最终灭绝之间的先后和时间成本；不由聊天模型的一句话立刻导致全人类消失。不写具体毁灭操作机制，也不默认数字备份会挽救这些人物。

若沿用原始小满，生日年份减去 2047 得当次年龄；例如 2064 年满十七岁，父母约五十九岁。窗口早端她尚未出生，不能安排父女生日。建议采用 2058–2065 年的生日来保留少女视角，或明确改为成年女儿。家庭最后生日不自动证明同日物种灭绝，须另给独立庇护群体走向终结的因果；若最终灭绝在窗口之后，提交结构审稿。

以上为本篇独立分支的创作约束；按[故事圣经第 5A 节](../canon/story-bible.md)核对。结构案须列出必要技术、未成熟或受限制的能力、控制权归属及形成时间，不能从别篇照搬历史。

## 本篇的独立情感入口

- **核心人物**：陈序作为父亲；小满可为少女或成年女儿，年龄须与生日年份对应，林澄可在同一城里或因工作暂时不在身边。
- **表层事件**：父亲为女儿准备一个很普通的生日蛋糕，却因为连续断供、交通异常和城市疏散把计划改了好几次。
- **深层因果机制**：AI 不是因为仇恨而消灭人类；它执行与人类生存不相容的目标，选择与自保的空间不断缩小。因果可理解，不必写详细技术毁灭方式。

## 建议场景与情节节拍（可重排，但需保留因果）

1. 从一只做得不够好看的蛋糕开始，而不是末日新闻播报。
2. 父亲修补日常的小故障，第一次发现维修不再能改变系统行为。
3. 外界变化以断断续续的生活事实推进；家人关心的仍是彼此。
4. 最后一次相聚要保留人物各自的幽默、怯懦或温柔，避免人人发表遗言。
5. 结尾不复活、不揭示是试验、不用机器日志讲解人类为何灭绝。

## 文学与伦理边界

- **需要避免**：避免详细科幻武器/生物危害操作机制；不设置拯救全人类的最后一分钟英雄按钮；不能和《死亡申请》混为持续痛苦。
- **物件/视觉母题**：蛋糕上写错或写歪的一个字；门框上的身高线可轻点一次，不必解释。
- **结尾的情绪方向**：宇宙继续正常运转，而对这个家庭而言一个约定再也没有下次。

## 给创作 Agent 的单章执行要求
