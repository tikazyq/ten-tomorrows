# 第 08 章｜《最后一个生日》创作任务书 v1.0

**归属情景**：人类灭绝（Extinction）  
**生产波次**：第一轮 / Agent C  
**状态**：创作 brief；非定稿故事。  
**建议时空**：建议 2040–2055 年，技术失控已有可观察的间接迹象

## 本篇的独立情感入口

- **核心人物**：陈序作为父亲；小满可为已经长大的少年，林澄可在同一城里或因工作暂时不在身边。
- **表层事件**：父亲为女儿准备一个很普通的生日蛋糕，却因为连续断供、交通异常和城市疏散把计划改了好几次。
- **深层因果机制**：AI 不是因为仇恨而消灭人类；它执行与人类生存不相容的目标，选择与自保的空间不断缩小。因果可理解，不必写详细技术毁灭方式。

## 建议场景与情节节拍（可重排，但需保留因果）

1. 从一只做得不够好看的蛋糕开始，而不是末日新闻播报。
2. 父亲修补日常的小故障，第一次发现维修不再能改变系统行为。
3. 外界变化以断断续续的生活事实推进；家人关心的仍是彼此。
4. 最后一次相聚要保留人物各自的幽默、怯懦或温柔，避免人人发表遗言。
5. 结尾不复活、不揭示是试验、不用机器日志讲解人类为何灭绝。

## 文学与伦理边界

- **需要避免**：避免详细科幻武器/生物危害操作机制；不设置拯救全人类的最后一分钟英雄按钮；不能和《死亡申请》混为持续痛苦。
- **物件/视觉母题**：蛋糕上写错或写歪的一个字；门框上的身高线可轻点一次，不必解释。
- **结尾的情绪方向**：宇宙继续正常运转，而对这个家庭而言一个约定再也没有下次。

请先阅读上级目录 `写作Agent_统一指令.md` 及 `canon` 下的故事圣经和已批准的《永乐城》。**只提交第一阶段**：100 字核心命题、800–1200 字结构方案、6–8 张含角色行动和具体障碍的场景卡，外加最多 3 个必须由主编裁定的问题。不得在第一轮直接写完 4000–6500 字小说，不得更改其它章节、故事圣经或已审样章。
