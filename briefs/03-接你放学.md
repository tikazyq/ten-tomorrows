# 第 03 章｜《接你放学》写作任务书

**归属情景**：渐进式失权（Gradual Disempowerment）  
**生产波次**：第一轮 / Agent B  
**状态**：创作 brief；非定稿故事。  
**建议时空**：2045–2070 年，一系列缓慢的制度变化之后

## v0.8 时间、技术与人物约束

分布式自动决策、招生与通勤优化、行政系统控制互相依赖；地方机构把计算、预算与规则执行长期外包，逐渐失去独立纠错能力。技术可以给出更好的试算，试算却不能自动取得跨机构执行权。本篇没有可集中撤换的唯一治理者，不使用无限准确预测或数字心智补足因果。

入学儿童、家长与行政人员可用新人物。若原始小满出场，按 2047 年出生参照核对当年年龄与学段；2045 年尚未出生，不能为共享名字把她提前放进校园。

以上为本篇独立分支的创作约束；按[故事圣经第 5A 节](../canon/story-bible.md)核对。结构案须列出必要技术、未成熟或受限制的能力、控制权归属及形成时间，不能从别篇照搬历史。

## 本篇的独立情感入口

- **核心人物**：一位普通学校行政人员或家长；共享人物可为小满，但不必让林澄全程在场。
- **表层事件**：一名学生因自动化分配规则遭遇不合理的入学安排；家长只想找到能签字改正的人。
- **深层因果机制**：每一层工作人员都善意、专业、遵照流程。多年前各机构自愿把决定权交给模型、监管框架和供应商的协商机制。没有一天宣布“AI 接管”，却没有任何人或机构还能真正承担最后决定。

## 建议场景与情节节拍（可重排，但需保留因果）

1. 展示申请人的个人现实：通勤、照护、朋友、可能被拆开的家庭安排。
2. 一个人认真处理申诉并努力帮忙，却只能传递意见。
3. 主角循着审批链找到上级，发现上级也必须征询其它系统，责任被分散。
4. 选择一份有瑕疵但能运行的解决方案，与继续申诉却让孩子误过时间。
5. 结尾留下一位善意办事员的真实歉意与无法更改的决定。

## 文学与伦理边界

- **需要避免**：不要套用秘密监控、AI 大反派或突然出现的“总统指令”。控制权丧失通过制度与经济依赖完成，与仁慈独裁的集中权力形成对照。
- **物件/视觉母题**：一张签字栏不断增加、真正的签字人却消失的申请单。
- **结尾的情绪方向**：一个人想负责却发现自己没有权限；痛点来自无人作恶、无人能改。

## 给创作 Agent 的单章执行要求

请先阅读[创作与审稿规范](../editorial/创作与审稿规范.md)、[故事圣经](../canon/story-bible.md)和[《永乐城》文学基准](../chapters/01-永乐城.md)。**只提交第一阶段**：100 字核心命题、800–1200 字结构方案、6–8 张含角色行动和具体障碍的场景卡，外加最多 3 个必须由主编裁定的问题。不得在第一轮直接写完 4000–6500 字小说，不得更改其它章节、故事圣经或已审样章。
