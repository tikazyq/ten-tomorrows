# 第 03 章｜《已办结》创作任务书 v1.1

**归属情景**：渐进式失权（Gradual Disempowerment）  
**生产波次**：第一轮 / Agent B  
**状态**：创作 brief；非定稿故事。  
**建议时空**：建议 2045–2065 年，一系列缓慢的制度变化之后

## 本篇的独立情感入口

- **核心人物**：一位普通学校行政人员或家长；共享人物可为小满，但不必让林澄全程在场。
- **表层事件**：一名学生因自动化分配规则遭遇不合理的入学安排；家长只想找到能签字改正的人。
- **深层因果机制**：每一层工作人员都善意、专业、遵照流程。多年前各机构自愿把决定权交给模型、监管框架和供应商的协商机制。没有一天宣布“AI 接管”，却没有任何人或机构还能真正承担最后决定。

## 建议场景与情节节拍（可重排，但需保留因果）

1. 展示申请人的个人现实：通勤、照护、朋友、可能被拆开的家庭安排。
2. 一个人认真处理申诉并努力帮忙，却只能传递意见。
3. 主角循着审批链找到上级，发现上级也必须征询其它系统，责任被分散。
4. 选择一份有瑕疵但能运行的解决方案，与继续申诉却让孩子误过时间。
5. 结尾留下一位善意办事员的真实歉意与无法更改的决定。

## 文学与伦理边界

- **需要避免**：不要套用秘密监控、AI 大反派或突然出现的“总统指令”。控制权丧失通过制度与经济依赖完成，与仁慈独裁的集中权力形成对照。
- **物件/视觉母题**：一张签字栏不断增加、真正的签字人却消失的申请单。
- **结尾的情绪方向**：一个人想负责却发现自己没有权限；痛点来自无人作恶、无人能改。

## 给创作 Agent 的单章执行要求

请先阅读上级目录 `写作Agent_统一指令.md` 及 `canon` 下的故事圣经和已批准的《永乐城》。**只提交第一阶段**：100 字核心命题、800–1200 字结构方案、6–8 张含角色行动和具体障碍的场景卡，外加最多 3 个必须由主编裁定的问题。不得在第一轮直接写完 4000–6500 字小说，不得更改其它章节、故事圣经或已审样章。

> 编辑备注：当前工作标题《已办结》尚未最终确认，要求通过具体情节验证，不可将现有行政处理场景机械地当作定稿。
