# 第 07 章｜《万亿分之一》创作任务书 v1.2（v0.8 世界观配套；待 PR 审核）

**情景**：数字人口陷阱／令人厌恶的结论（Repugnant Conclusion）｜**波次**：第二轮
**时空**：2200–3000 年及以后；建议约 2500 年，距分歧点数百年至千年后

## v0.8 时间、技术与人物约束

本线额外假设可承载主观体验的数字心智成立。作者须说明：数字心智出现 → 复制成本下降与人口扩张 → 计算经济和分配制度形成 → 人均体验资源受限。计算架构与资源优化再先进，能源、散热、物理计算容量与分配制度仍有限；不从 LLM 输出直接推断意识。此为科幻前提，未被现实研究证明；本篇不靠恶意 AI 施刑推动。

优先采用原生数字公民；若与小满有联系，交代档案、复制、保存或迁移的历史，不把同名自动认作原人。外部历时、清醒/体验时长与处理速度分开；几毫秒算力不是自动等于几毫秒主观生活。

以上为本篇独立分支的创作约束；按[故事圣经第 5A 节](../canon/story-bible.md)核对。结构案须列出必要技术、未成熟或受限制的能力、控制权归属及形成时间，不能从别篇照搬历史。

## 故事入口

- 人物：有职业、偏爱、亲密关系和记忆的数字公民，不能只是抽象数据。
- 事件：一次算力份额重分配缩短了主人公每天清醒的时间，她只想陪重要的人完成一件小事。
- 机制：复制成本降低促成极多有意识个体，竞争使人均资源接近最低可接受水平；这不是恶意永恒折磨。

## 场景与节拍

1. 用感知限额、有限清醒时间建立日常。
2. 呈现亲密关系如何被时钟与资源限制。
3. 新的复制个体与总体份额之间存在可理解的制度因果。
4. 主角可通过侵占别人的配额改善生活，但需面对伦理代价。
5. 留下一次微小却真实的个人经验，与文明总量形成尺度反差。

## 边界与母题

数字生命具有尊严；与《死亡申请》的持续受刑故事严格区分。可以使用迟迟加载完成的一段私人录音或一种颜色。不使用术语做文学结尾。
